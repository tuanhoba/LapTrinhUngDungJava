## 2. Mục Tiêu Môn Học
- Hiểu được các khái niệm cơ bản của lập trình Java.
- Thành thạo lập trình hướng đối tượng (OOP) trong Java.

- Kết hợp lý thuyết và thực hành.

- Học trực tiếp hoặc trực tuyến theo lịch học.

## 4. Nội Dung Môn Học
### **Phần 1: Tổng Quan Về Java**
1. Giới thiệu về Java và cài đặt môi trường phát triển (JDK, IntelliJ, Eclipse)
2. Cấu trúc chương trình Java
3. Biến, kiểu dữ liệu, toán tử
4. Câu lệnh điều kiện và vòng lặp

### **Phần 2: Lập Trình Hướng Đối Tượng (OOP) Trong Java**
5. Lớp và đối tượng
6. Phạm vi truy cập và đóng gói
7. Kế thừa và đa hình
8. Interface và abstract class
9. Xử lý ngoại lệ (Exception Handling)

### **Phần 3: Làm Việc Với Dữ Liệu Trong Java**
10. Collection Framework (List, Set, Map)
11. Streams và Lambda Expression
12. Đọc/ghi file với Java IO & NIO

### **Phần 4: Lập Trình Giao Diện Đồ Họa**
13. Giới thiệu về Swing
14. JavaFX cơ bản

### **Phần 5: Kết Nối Cơ Sở Dữ Liệu**
15. JDBC - Kết nối Java với MySQL
16. ORM với Hibernate

### **Phần 6: Lập Trình Web Với Java**
17. Servlet & JSP
18. Framework Spring Boot

### **Phần 7: Đồ Án Cuối Khóa**
19. Xây dựng ứng dụng thực tế bằng Java
20. Trình bày, bảo vệ đồ án
