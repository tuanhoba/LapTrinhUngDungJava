# LapTrinhUngDungJava
Hiểu được các khái niệm cơ bản của lập trình Java.  Thành thạo lập trình hướng đối tượng (OOP) trong Java.  Xây dựng ứng dụng Java với giao diện đồ họa (Swing, JavaFX).  Kết nối cơ sở dữ liệu với Java (JDBC, Hibernate).  Phát triển ứng dụng Java trên nền tảng Web (Servlet, JSP, Spring Boot).
