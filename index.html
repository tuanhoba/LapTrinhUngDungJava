2. Mục Tiêu Môn Học

  • Hiểu được các khái niệm cơ bản của lập trình Java.
  • Thành thạo lập trình hướng đối tượng (OOP) trong Java.
  • Xây dựng ứng dụng Java với giao diện đồ họa (Swing, JavaFX).
  • Kết nối cơ sở dữ liệu với Java (JDBC, Hibernate).
  • Phát triển ứng dụng Java trên nền tảng Web (Servlet, JSP, Spring Boot).

3. Phương Pháp Học

  • Kết hợp lý thuyết và thực hành.
  • Làm bài tập theo từng chủ đề.
  • Thực hiện đồ án cuối khóa.
  • Học trực tiếp hoặc trực tuyến theo lịch học.

4. Nội Dung Môn Học

  • Giới thiệu về Java và cài đặt môi trường phát triển
  • Cấu trúc chương trình Java
  • Biến, kiểu dữ liệu, toán tử
  • Câu lệnh điều kiện và vòng lặp

  • Lớp và đối tượng
  • Phạm vi truy cập và đóng gói
  • Kế thừa và đa hình
  • Interface và abstract class
  • Xử lý ngoại lệ (Exception Handling)

  • Collection Framework (List, Set, Map)
  • Streams và Lambda Expression
  • Đọc/ghi file với Java IO & NIO

  • Giới thiệu về Swing
  • JavaFX cơ bản
